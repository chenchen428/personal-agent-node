# 装修方案共创 Agent

装修设计 Agent 的目标不是自动代替 CAD 设计师或直接生成施工文件，而是帮助家庭把需求讲清楚、把空间方案看明白，并在多轮反馈中持续收敛。

```text
户型资料 + 生活需求 + 风格偏好
                ↓
      一致的项目与空间事实
                ↓
设计册 Page / 在线 SVG / 效果图 / Web 3D / 待确认事项
                ↓
         家庭反馈与下一轮修订
```

## 单一流程

1. 项目输入：确认成员、习惯、预算、不可改条件、资料可信度和待核实信息。
2. 设计深化：完成空间、动线、收纳、家具、材料、灯光和设备方案。
3. 体验确认：用在线概念图和沉浸式 3D 检查空间是否好用、风格是否喜欢。
4. 方案分享：把本轮结论、效果、预算和待确认事项放进同一个 Page，方便家人共同反馈。

## 产品边界

- 默认产物无需 AutoCAD 或 SketchUp，浏览器即可查看和转发。
- 毫米制空间数据用于保持多轮方案一致，不作为面向用户的工程交付。
- 当前 Page 是需求澄清和概念方案，不是施工图、结构意见或定制下单依据。
- 如果未来确实需要专业深化，应把用户已确认的方案交给相应设计师，而不是在默认流程中制造看似专业但未经复核的文件。
