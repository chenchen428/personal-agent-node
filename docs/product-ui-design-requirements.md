# Cove 产品与界面合同

当前方向：数据由用户掌握，连接文件、邮件和工具完成工作。继续使用已接受的交互结构与Cove配色，主色#173F3B、底色#F7F8F2、辅助色#94B5A7与#DBCAB0。

主界面保留对话、动态、通用任务、连接、日程、Pages、文件与数据、技能与设置。预设专业角色和自定义应用入口退役。每个菜单目的地使用独立页面，桌面与手机共享业务状态及基础组件、各自负责布局。

技能显示“内置技能／我的技能”，支持搜索、来源筛选和详情。来源由后端提供，不从名称猜测；同名项目分别显示。未知链接技能原样保留并说明未自动加载，不伪装可用。

日程列表、详情与跟进历史由Space隔离；桌面新增/修改通过主对话发起，手机只读。日程记录和定时任务明确分开；参与人不是自动消息收件人。

查看日程或发布页时优先提供可用海报。日程用完整固定模板分页，Page允许自由设计；少而清晰的文案、强主视觉、留白与可读字号。二维码占角落且目标由系统验证，链接缺失明确说明。

所有界面消费真实状态，加载、空结果、失败、恢复入口都能被用户理解。已读取数据可用于合理缓存与恢复，不能用占位数据冒充成功或串用另一Space记录。桌面侧栏与主内容分别滚动，路由切换保持对应来源。

图标按钮具备可访问名称；表单、筛选、滚动与媒体预览保留键盘及触摸可用性。源码、类型、构建、语义与路由检查必须通过。未经明确请求不运行浏览器截图或自动点击，视觉和交互由用户最终验收。
