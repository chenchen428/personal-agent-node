# ADR 0013：装修设计同场景高质量产出合同

- 状态：已接受
- 日期：2026-08-01
- 决策范围：`interior-designer` Agent、`interior-design` Skill、Pascal v2 场景、装修设计 Page 交付

## 背景

当前装修设计已经具备需求确认、户型证据、结构化空间、Pascal 三维场景、空间质量审计和 Page 交付，但材质、灯光、相机与概念效果图仍是松散信息。实时三维主要使用程序化几何和固定颜色，效果图虽然受提示词与参考图约束，却没有显式绑定同一份可验证的场景质量合同。

这会造成三类质量损失：

1. 平面、三维、效果图和清单可能在不同时间各自修改，无法证明来自同一版设计。
2. 材质只有名称和颜色，缺少粗糙度、金属度、用途等可渲染参数；灯光与相机只有描述，没有可复现的镜头。
3. 空间审计能发现碰撞和动线问题，但无法阻止缺少渲染参数、镜头或几何锁定声明的方案进入最终交付。

## 决策

### 1. Pascal v2 是唯一场景真相源

项目的空间、构件、家具、材质、灯光和交付镜头必须先进入项目 v2 合同，再由 Pascal 适配器编译为一个确定性场景包。平面、三维、质量报告和 Page 不允许维护独立的几何副本。

编译场景哈希覆盖：

- Pascal 建筑场景；
- 家具和资产实例；
- 可渲染材质表；
- 灯光方案；
- 交付相机；
- 渲染与几何锁定策略。

上述任一内容变化都产生新的场景哈希，旧效果图不再能冒充当前版本。

### 2. 设计意图升级为可执行质量合同

`designIntent` 保留风格和维护说明，并新增以下结构化要求：

- 材质：稳定 ID、基础色、类别、粗糙度、金属度、湿区适用性和维护说明；
- 灯光：稳定 ID、类型、位置、目标、强度、色温与适用房间；
- 相机：稳定 ID、名称、用途、位置、目标、视场角与排序；
- 渲染策略：实时预览配置、最终表达配置、几何锁定、控制通道和 AI 增强策略；
- 资产实例：稳定资产 ID、版本、锚定方式、缩放策略和操作净空。

合同只接受本地、确定性、可脱机消费的数据。远程模型、远程纹理和运行时网络依赖不进入 Page。

### 3. 效果图是场景绑定证据，不是新的设计源

最终效果图允许使用受控增强，但必须满足：

- 几何锁定开启；
- 指向当前编译场景哈希；
- 指向一个已定义的交付相机；
- 记录参考图哈希和提示词哈希；
- 不得增删门窗、墙体、固定柜体、主要家具或改变尺度关系。

当前版本实现合同、哈希绑定、实时 PBR 预览和交付镜头。离线光追、深度图/法线图生成和自动几何一致性视觉比对属于后续渲染后端，不在本轮宣称范围内。

### 4. 质量门禁由“能打开”提升为“可复现、可比较”

以下问题阻断编译或发布：

- 引用未定义材质；
- 材质缺少合法颜色、粗糙度或金属度；
- 没有可执行灯光；
- 没有交付相机，或相机位置与目标无效；
- 最终表达未开启几何锁定；
- 受控 AI 增强缺少必需控制通道；
- 资产 ID、版本、锚定方式或缩放策略不完整；
- 编译场景中的质量合同与项目不一致。

材料样板、现场复尺、结构、防水、机电和当地法规仍由相应专业人员核验，软件门禁不能替代这些责任。

## 产品流程

1. 需求确认：先确认户型依据、家庭成员、功能、风格边界、预算和未知项。
2. 空间方案：完成结构化房间、墙体、门窗、家具、固定设施与净空。
3. 设计系统：选定小而一致的材质表、灯光分层和资产规格。
4. 镜头设计：为公共区、重点立面和私密空间定义可复现相机。
5. 同场景编译：生成 Pascal 场景包和统一哈希。
6. 自动审计：空间、材料、灯光、相机、资产和交付证据全部通过后才能发布。
7. 交付验收：用户在 Page 中比较同一场景的三维、平面、效果图、需求和专业边界。

## 本轮验收标准

- 代表项目包含完整的材质、灯光、相机、渲染与资产合同。
- Pascal 编译结果携带去敏后的 `designQuality`，且场景哈希覆盖该字段。
- Page 实时三维使用项目材质参数、项目灯光和首选交付相机。
- Page 可切换已定义镜头，并展示当前设计质量摘要。
- 质量报告能阻断材质、灯光、相机、资产、几何锁定和控制通道缺陷。
- 代表性交付可确定性重建，所有既有空间、安全、隐私和离线门禁继续通过。
- 最终安装包来自完成版本、公共面和安装验收的 Node 发布候选。

## 后续演进

- 引入可审计的本地资产库和真实 PBR 纹理包，但保持 Page 离线与内容寻址。
- 增加深度、法线、语义和对象 ID 控制通道的确定性生成器。
- 接入离线光追渲染后端，并以同一相机和场景哈希生成最终图。
- 对受控增强图执行结构线、对象数量、门窗位置和相机投影的一致性检测。
- 将材料样板、报价、供应商和采购替代项绑定到稳定材质及资产 ID。
