# ADR 0015：Cove轻量能力与技能来源

状态：当前执行合同，取代旧专业角色与自定义应用模块相关约定。

保留通用对话、Workers、连接、Pages、插件、文件、数据、Activity、Memory、备份和更新。增加空间日程与受管海报交付；不恢复预设专业角色、阶段审批工作流或App宿主。

发行内置仅13项cove技能，原personal-*改名。内置来自不可变发行目录，用户技能留在各Space的agent-workspace/skills。catalog的id与source.kind由实际来源决定，任何前缀、frontmatter或可变registry都不能声称内置所有权。

legacy-builtin-skills.json记录旧干净发行版本的完整Git文件树指纹，仅在全部文件及hash一致时将旧副本排除默认发现。所有用户修改、额外文件、未知来源、符号链接和既有备份保留，不按名称搬移或删除。普通AGENTS.md只有与受信旧默认种子逐字节一致时才能原地刷新。

UI和两引擎使用同一resolver。Codex在每个产品进程/线程验证原生技能禁用配置，并通过turn/start开发者指令刷新索引；Claude关闭原生slash发现，通过本轮系统索引按需读取。用户新技能下一轮可见，未支持隔离配置的引擎明确失败，不改写全局配置。

Calendar记录事项与跟进，不等于cron。日程读写限定当前Space和主会话临时能力；日程变更不会自动提醒或联系参与人。用户明确要求未来执行时再使用cron。

Page海报自由设计，日程海报使用固定完整分页模板；二维码由系统绑定可用当前目标链接。图片登记为受管对象，由主回复返回。视觉与浏览器交互最终由用户验收。
