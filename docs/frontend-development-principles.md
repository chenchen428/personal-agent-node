# 前端工程原则

适用于Cove桌面与移动端。一个组件只有一个主要职责；页面负责组合，状态、数据读取、布局和可复用呈现按变化原因拆开。

复用现有导航、输入、筛选、分页、加载、空状态和错误恢复组件，不复制一整套页面。每个菜单目的地对应独立页面组件。每个 `.tsx`/`.jsx` 文件不超过300物理行，不通过压缩源码规避限制。

桌面侧栏和主内容分别滚动。移动端使用独立页面组合，共享数据和基础组件，不能把桌面页面简单缩窄。切换路由保留正确来源、有效选择和必要阅读位置。

使用真实数据状态，不伪造加载完成、成功结果或客户内容。图标按钮有明确可访问名称；链接和操作与标签承诺一致，键盘与触摸入口可用。

视觉和浏览器交互由用户验收，未明确请求时不截图或自动点击。代码、类型、构建、语义和路由测试照常执行：

```bash
npm run frontend:guard
npm run app:typecheck
npm run app:build
```

日程入口固定只有日程和执行记录两个视图。使用相同的模块标题、说明、切换栏和摘要区域；数据筛选位于相同工具栏行，范围切换保持靠左。计划详情留在日程的上下文中，旧链接保持兼容。

空间切换保持侧栏与顶栏几何布局，使用真实连接/打开状态和不透明骨架遮住旧空间内容。目标空间在确认身份前只显示固定产品骨架。先准备当前页面数据，其他菜单在同一scope后台预取；所有迟到结果必须经过generation和abort检查。切换不携带原空间记录ID或搜索内容，尊重减少动画设置，失败可恢复且不能虚构百分比进度。

## 用户技能管理

本机桌面的空间设置中，“我的技能”支持导入 SKILL.md 或含文本资源的技能目录、确认移除，以及撤销移除。内置技能不可移除；同名不能覆盖。移除前校验当前内容摘要，原目录移入当前空间内的回收区，保留原文件。导入不运行脚本，需通过名称、路径、大小和安全检查。每次新回合从共享技能目录读取有效技能，当前空间的变更不影响其他空间。
