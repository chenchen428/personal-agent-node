# Cove 日程与定时任务

先区分用户意图：

- 记录会议、约定、行程，查看某段时间安排或补充进展：使用日程。读取 [calendar.md](references/calendar.md)。
- 在未来提醒、定期执行或修改自动化计划：使用定时任务。读取 [scheduled-tasks.md](references/scheduled-tasks.md)。

日程不是 cron。记录参与人、起止时间、IANA 时区、地点、状态及后续跟进；如用户同时要求提醒，再明确创建对应定时任务。不要将跟进时间自动转换为通知。

日程写入仅由当前主 Agent 使用本轮临时能力，修改与跟进携带最新 revision。定时计划变更后从服务重新读取并核对时间、提示内容与下次运行。

查看最近日程、下一次安排或未指定范围时，先实际执行 `pa-cli calendar list --view upcoming --limit 1`（带本轮能力和 `--json`），不要默认只查今天或未来7天。先用文字明确 `nextEntry` 的完整年月日、时间、时区和事项；有 `ongoingEntry` 时另行说明正在进行，不能把它当成尚未开始的下一次。查询成功且没有下一项才说暂无后续安排，查询失败就说明无法确认。

需要图片或一览时，在文字答案后优先返回系统固定模板海报，使用 `pa-cli calendar poster`；根据已查到的安排选择范围，或用 `--id` 展示下一项，不能因近几天空白而遗漏更远的下一次安排。完整展示所选范围，不截断或挤成小字。二维码由系统绑定当前空间可用手机地址。图片用主回复受管附件返回；链接不可用时说明原因，仍给出已核实的文字日程，不自行生成外链二维码。
