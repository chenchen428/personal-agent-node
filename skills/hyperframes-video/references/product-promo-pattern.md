# Continuous product-promo pattern

Use this pattern when a reference feels like a polished product launch rather than a sequence of presentation slides.

## Visual grammar

- Start with a short logo or object-convergence beat.
- Move into one continuous, dark product canvas.
- Keep a subtle grid or workspace texture behind the UI.
- Let product elements assemble, connect, stamp, drag, type, or resolve in place.
- Use pointers, selection handles, measurement labels, or focus rings to make interaction legible.
- Maintain a restrained caption rail near the lower safe area.
- Reserve the largest type and strongest contrast for the closing brand promise.

## Motion grammar

- Give every object an origin and destination.
- Use a small easing vocabulary instead of unrelated effects.
- Animate state changes on the shared canvas; avoid resetting the entire frame between features.
- Use short blur, scale, or depth transitions only at major narrative boundaries.
- Let cursors or agent markers move with organic arcs, then settle precisely on targets.
- Keep the last frame still long enough to read.

## Product adaptation

Map the reference’s canvas behavior to the actual product model. For Personal Agent:

- the main Agent receives the user goal;
- specialist Agents branch from the main Agent;
- their outputs return to the main Agent;
- the user sees one coherent delivery surface;
- local boundaries and governed external actions remain truthful.

Borrow the rhythm and composition logic, not the reference product’s logo, wording, interface chrome, or proprietary assets.
