# 用户工作区交付 V5

`pages/index.html` 是默认入口，按业主视角解释方案，不介绍内部工作区和生成技术。

- 六类 SVG 分别表达平面、天花灯具、开关控制、插座、给排水和柜体，不允许用同一内容换色冒充不同图纸。
- `pages/3d/index.html` 是可进入查看、可修改的语义草图；门窗、柜体、灯具和全景相机位置必须可辨认。
- 草图确认后，每次只推进一个视角。相机由用户确认；Blender 结构控制底稿由质量门禁自动确认；系统把设计、相机、控制图和前序风格参考编译为带哈希的提示词包；Codex Imagegen 依据该提示词包一次生成一张完整的照片级 2:1 实景全景图，再由用户确认。
- `pages/panorama-review/index.html` 通过本地 360° 球面查看器展示 Imagegen 实景全景及逐视角状态，不向用户展示内部控制底稿，也不隐藏失效或待重做状态。
- 全部 Imagegen 实景全景确认后，使用合法授权的 `krpano.js` 组装 `pages/tour/`，再走查热点、初始朝向、移动端和全屏。
- Page 只使用同源相对资源，不发布原始证据、绝对路径、远程运行时或内部 JSON 下载。

任何反馈修改对应过程产物，并按依赖关系只使受影响的下游失效。视觉与交互最终验收归用户。
