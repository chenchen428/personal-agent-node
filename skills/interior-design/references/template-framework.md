# 装修设计交付页模板框架

以 Personal Agent Pages 的装修设计模板为实现基础。模板只固定高质量交付所需的交互框架，不固定设计答案。

## 固定框架

- 首屏直接显示完整的 Three.js 概念模型，空间关系、楼层关系和主要家具可辨识。
- 轴测、顶视、漫游相机与重置操作均可用；复式模型额外提供整体、下层、上层、挑空剖切和自由查看。
- 使用 OrbitControls 主动旋转、平移、缩放；不提供自动巡游、时间轴或播放控件。
- `presentation.reveal` 只负责说明垂直空间生长，必须尊重 reduced-motion 并在用户交互时立即结束。
- 空间浏览默认是整体方案。选择房间后相机真正进入对应楼层的近景。
- 桌面使用独立空间索引与全画布；移动端使用全画布、Header 空间选择和不遮挡主体的上下工具带。
- WebGL 不可用时展示同一模型的可拖动投影降级，不退化为空白。
- 页面只读；用户通过自然语言让 Agent 修改结构模型并重新发布。

## Agent 自由发挥

根据户型证据和用户意图决定房间几何、连通关系、楼层覆盖、楼梯与栏杆、家具、材质、灯光、命名和默认镜头。这些内容不得硬编码为示例户型。只有交互框架、设备适配、概念精度说明和安全边界是稳定约束。
