# Changelog

All notable changes to Photo to Zine Postcard will be documented here.

## [1.0.0] - 2026-08-07

### Added

- First public release of `photo-to-zine-postcard`.
- Original-photo embedding with preserved aspect ratio.
- Fixed minimal 2:3 postcard composition.
- Hand-drawn-first source motif selection and rendering.
- Three source-derived color swatches.
- Unified functional postcard back.
- High-detail rendering guidance for later 4× super-resolution.
- Public customization guidance for forks and derivative styles.
