# Contributing

Photo to Zine Postcard is intentionally easy to fork and customize.

## Ways to contribute

- improve the core `SKILL.md`
- add new postcard style variants
- contribute example outputs
- improve motif selection rules
- test unusual source-photo ratios
- improve multilingual usage instructions
- report unstable generation patterns

## Design constraint

Please keep contributions aligned with the project’s central idea:

> The original photograph stays primary; the lower zine area should remain sparse, source-specific, and subordinate to the photo.

Avoid turning the default skill into a dense poster, mood board, texture sampler, or multi-card layout.

## Pull requests

For visual changes, please include:

1. what rule changed
2. why the change improves consistency or visual quality
3. at least one before/after example when possible
4. whether the change affects the default style or only an optional variant

For major stylistic experiments, prefer adding a variant rather than changing the default skill.
