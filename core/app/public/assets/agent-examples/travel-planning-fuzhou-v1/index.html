01 / TRIP BRIEF

先锁定不会移动的条件

这份安排围绕固定酒店、双城会合、梅雨季和早班返程组织。任何新增停点都必须先证明不破坏回酒店休息与返程缓冲。

住宿基点南门兜附近连住 3 晚

不换酒店。老城核心区以步行或短打车解决，雨天可以随时回房换鞋休息。

抵达约束两位同行者在福州站会合

抵达夜不跨江，不安排需要预约或长距离移动的项目。

体力节奏每天 2–3 个优先停点

连续步行 90 分钟后安排坐下休息；山路与长街不放在同一时段。

天气假设阴雨为主，随时切换

雷雨时取消乌山与福道；保留古厝、廊道、咖啡与水疗等近距离备选。

  1. 已固定
    酒店位置与三晚连住

    所有日程以南门兜为起终点，避免换房和搬运行李。

  2. 优先保留
    西湖水系、三坊七巷、上下杭

    覆盖福州老城、水岸与闽商街区三条不同体验线。

  3. 可删减
    福道、远距离锅边、水疗

    雨大、晚点或早车过早时直接删除，不挤压核心路线。

  4. 待复核
    门店营业、游船班次、返程车次

    出发前 24 小时重新查询并更新 Page 状态。
